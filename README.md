## Featured projects

### [Telegram Ops Alerts](https://github.com/Utasu/telegram-ops-alerts)

Deduplicates JSON events in SQLite and routes actionable alerts to Telegram. Includes severity rules, preview mode, safe URL validation, and offline tests.

### [VPS Health Audit](https://github.com/Utasu/vps-health-audit)

Produces a read-only Linux health report covering memory, CPU-normalized load, disk pressure, failed systemd units, and listening-socket counts.

### [Web Change Monitor](https://github.com/Utasu/web-change-monitor)

Monitors authorized HTTPS pages with ETag support, normalized text snapshots, bounded diffs, SSRF protections, and optional Telegram notification.
